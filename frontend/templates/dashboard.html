Before You Begin

Interactive checklist for first-time users — progress is saved on this browser.

0 of 8 complete 0%
  • You’re here — mark complete once the Dashboard loads after install.
  • Use Update Tools in the header so vnetmap and related scripts are current.
  • Save cluster IP and credentials on the Reporter page for reuse.
  • Tech Port, VMS Mgmt, or Teleport — pick the mode that matches site access on Reporter. See the Field Procedure for which IP to enter.
  • Open Discovery on Reporter, place switches (and non-VMS switches via +Switch), then Save to Profile.
  • On Reporter, run As-Built alone or the full post-deploy Test Suite (vnetmap, support tools, health, and more).
  • Grab outputs from Results (and legacy Reports if needed).
  • Attach PDF/JSON/bundle to the customer SFDC account and #internal-<customer>. Follow the Field Procedure (or Docs).

Deployment Workflow

1
Connection Settings

Create or select a Cluster Profile, then choose a connection mode. Autofill passwords when enabled (see Advanced).

  • Tech Port: use 192.168.2.2.
  • VMS Mgmt: use the VMS VIP over the network.
  • Teleport: connect via Teleport to the CNode target.
Open Reporter
2
Discovery & Switch Placement

Click Discovery to open the Switch Placement Editor. Run Discovery, assign switch U-heights (top-U for 2U devices). Optionally add customer-managed switches with +Switch, then Save to Profile.

Configure
3
Run Report or Test Suite

On Reporter, choose an operation path:

  • Reporter: Pre-Validation, As-Built Report, Health Check
  • Test Suite: full post-deploy checklist (vnetmap, support tools, bundles, and more)

Click Run, then monitor progress in Output Results.

Run
4
Review & Download

Download PDF, JSON, and cluster bundles from Results once jobs complete. Review SUMMARY.md status before posting to SFDC and Slack.
