### Fixed
- **Results cluster filter (TP-4):** clusters reported through the Tech Port no longer mix on the Results page. Each one gets its own Cluster Filter entry, labelled with the cluster name and IP. Selecting it lists only that cluster's reports, health checks, workflow outputs and bundles. Before, every Tech Port cluster shared the IP `192.168.2.2`, so choosing one listed them all.
- **Older Tech Port results (TP-4):** results saved before per-cluster folders that carry only `192.168.2.2` are no longer shown under a Tech Port cluster. They appear under a new "Unassigned (legacy)" entry. Clusters reached over VMS HTTPS still filter by their IP as before, and old `?cluster_ip=` links keep working; a `?cluster_ip=192.168.2.2` link now opens the Unassigned (legacy) list.
